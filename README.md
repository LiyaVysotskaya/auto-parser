# market-slice

Монорепозиторий для работы со срезом рынка автомобилей. Включает следующие пакеты:

- [@market-slice/auto-ru](packages/auto-ru/README.md) - инструменты для получения среза с [Auto.Ru](https://auto.ru)
- [@market-slice/application](packages/application/README.md) - консольное приложение
- [@market-slice/ui](packages/ui/README.md) - react-интерфейс пользователя
- [@market-slice/electron](packages/electron/README.md) - десктопное приложение

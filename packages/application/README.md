# @market-slice/application

Консольное приложение для получения среза рынка автомобилей.

## Использование

```bash
npx @market-slice/application -h
```

## Использование как библиотеки

```bash
npm i @market-slice/application
```

```javascript
import { store, autoRu } from "@market-slice/application";

await autoRu.action();

//...
```
